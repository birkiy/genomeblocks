# This page has moved
{: .no_toc }

In genomeblocks 2.0 the columnar tables *are* the package: `Loci`, `Genes`,
`Pairs`, `Architecture` and `Atlas` are the tables, and there is no separate
`genomeblocks.columnar` subpackage. The design of the tables is now explained
on [Design → Tables]({{ '/design/tables/' | relative_url }}).

What changed from 1.x is listed on the
[Release Notes]({{ '/release-notes/' | relative_url }}) page.
