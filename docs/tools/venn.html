Runs entirely in your browser — nothing is uploaded. The set semantics mirror [`Loci` algebra](../guide/loci#set-algebra): each Venn region counts **merged intervals** after collapsing overlapping peaks across all input files. {: .fs-5 .fw-300 }

Drop .bed or .narrowPeak into the slots on the left. Adding a third file switches to a 3-way Venn.
Counts are merged intervals per region (bedtools-multiinter style). Overlap is any shared base — equivalent to Loci.make(a) & Loci.make(b) after sort().merge().
## What this mirrors The diagram above is the browser-side counterpart of this Python: ```python from genomeblocks import Loci a = Loci.make("file_A.narrowPeak").sort().merge() b = Loci.make("file_B.narrowPeak").sort().merge() c = Loci.make("file_C.bed").sort().merge() # 2-way regions a_only = a - b # len → "A only" b_only = b - a # len → "B only" shared = a & b # len → "A ∩ B" # 3-way regions (merged-universe count) union = (a | b | c).sort().merge() region = { "A only": len(union - b - c & a), # merged intervals touched only by A "A ∩ B only": len(((a & b) - c).sort().merge()), # …one entry per Venn slice } ```
