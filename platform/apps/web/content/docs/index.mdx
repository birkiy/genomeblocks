# Introduction

**Genomeblocks** is a Python library for regulatory genomics. Everything is chainable: the output of one stage is always a first-class object accepted by the next.

```python
cre = peaks.slop(100).sort().merge()
```

The primary surfaces are:

- **This documentation site** — start here; every public API is covered.
- **The dashboard** — the same pipelines, in your browser, against your own files. Open it at [/app](/app).
- **The Python package** — install with `pip install genomeblocks`.

## What's new in this platform

The docs and the dashboard now live on the same domain. Links between them are relative and fast. The dashboard runs real Python on the server against a sandboxed per-session drive — no local install required to try things out.

Continue with the [Quickstart](/docs/quickstart), or read about the [architecture](/docs/architecture) if you're wondering how the dashboard works under the hood.
