# Quickstart

## Install

```bash
pip install genomeblocks
```

## Load peaks as Loci

```python
from genomeblocks import Loci

peaks = Loci.from_bed("atac_peaks.narrowPeak")
peaks.head()
```

## Chain operations

```python
cre = (
    peaks
    .slop(100)     # extend by 100bp on each side
    .sort()
    .merge()       # collapse overlaps
)
```

## Run the same thing in the browser

Open the [Venn playground](/app/playground/venn), drop three BED/narrowPeak files in, and the dashboard will compute their 3-way overlap the same way you'd compute it locally — except it runs on the server against a scratch directory scoped to your session.
